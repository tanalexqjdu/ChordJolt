# ChordJolt

ChordJolt enables real-time data processing through a distributed architecture, performance and reliability via scalable Manager and Agent components.

With ChordJolt, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/ChordJolt.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ChordJolt is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
